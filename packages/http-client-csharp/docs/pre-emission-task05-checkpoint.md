## Bounded behavior

Under the existing opt-in pre-emission policy, a finalized native file can prepare
omission of the outer grouping on a direct return/arrow `int`-parameter equality
whose result is `bool`. Preparation uses the original structured occurrence and
actual parameter correspondence; expression type hints alone are not authority.
The no-recorded-type-reference case needs no dummy field or reference.

The first profile requires the audited native header/member/factory contracts,
XML documentation disabled, an empty native type-factory map, complete current
source inputs, and a closed supported file. Unknown inputs retain native output.
Required right-associated subtraction grouping and observed lambda source text
remain unchanged. This profile does not shorten arbitrary binary families.

The standard writer runs once. Each actual omission has a file/generation/node
identity and is checked against the writer's consumption receipt. Native fallback
text is captured during that same traversal; preparation does not parse generated
text or mutate a shared `AddParentheses` flag. Child type spellings remain native.

Selection retains independent name-only files, but does not infer permission for
unsupported same-file grouping/type-name composition. After callbackful commit
checks, a final data seal revalidates the bounded facts before all selected files
are materialized and publication callbacks run. Observed invalidation is sticky.
Cold file warnings use owner-bound facts rather than invoking a lazy builder.
Before any final currentness walk, a nonforcing preflight checks all captured
files for cached parameter spellings, including indexer formals and frame-held
parameters hidden by opaque signatures. An unavailable spelling vetoes grouping
only, without calculating a name or poisoning shared facts; later canonical
materialization can enable a subsequent valid seal. Grouping discovery rejects
unknown method/parameter attribute collections through the shared collection
contract without calling their accessors. Structured-source capture additionally
requires actual cached native parameter spellings before it can activate a newly
supported binary frame. If unavailable, it retains the old no-frame result rather
than adding name-calculation callbacks. Explicit frame observations and inherited
nonbinary profiles keep their original ordering and fallback.

## Currentness and allocation

The finite equality-region optimization compares retained statement, keyword,
binary, variable, type and declaration facts at the original frame observation
point. Signature and parameter checks keep their original order. Any fast-path
miss or unsupported profile uses the original full shape check; no successful
result is cached across callbacks and no observations are batched away.

These are small-fixture observations, not production benchmark guarantees.
Remaining signature/parameter snapshot and hashing overhead is accepted follow-up

source completeness, lifetime, review, or validation requirements.
